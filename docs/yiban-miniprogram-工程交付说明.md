## 二、已锁定的产品规则（全部代码化）

| 规则 | 实现 |
|---|---|
| 性别自动配（男配女 / 女配男） | `pool.drawPortrait` 按 userGender 反选目标性别 |
| 年龄差 ≤5 优先 | lunar.js `matchBuckets` + pool 过滤 |
| 气质偏好（清冷/阳光/温润/疏离） | 四档必选，图池按 style 索引 |
| 5%「反差缘分」跳出常规 | 5% 概率全池随机，文案标注 |
| 再抽不连抽同一张 | `pool.redraw` 排除 lastId |
| 国学包装·避玄学 | 全部文案用「生肖/节气/星座/国学趣味」，无八字/命理/运势 |
| 页脚合规 | 每页固定「AI 生成 · 内容仅供娱乐参考」 |
| 地域可选（默认不透露） | form 页 chips，不进主流程 |
| 性格测试不阻塞 | result 页钩子入口，完成后标签追加「性格 · MBTI」 |
